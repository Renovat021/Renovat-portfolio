System Architecture & Technical Stack

Back-End: PHP business logic & authentication middleware
Database: MySQL (Tables for Vehicles, Owners, Customers, Bookings)

Key Responsibilities & Accomplishments

  • Engineered multi-role authentication (Car Owner vs. Customer interfaces).
  • Created an interactive vehicle catalog with specs filtering (transmission, fuel, seating capacity).
  • Implemented backend logic to prevent double-booking on overlapping calendar dates.
